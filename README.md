# 知意输入法语言包词表 / Zhiyi IME language pack word lists

[知意输入法](https://github.com/dd1000001000/zhiyi_ime)的学习模式在候选窗口里给每个候选显示它的外语意思和词性。
这里是那些翻译的词表，欢迎一起改进。

The learning mode of [Zhiyi IME](https://github.com/dd1000001000/zhiyi_ime) shows what each
candidate means in another language. These are the word lists behind it; corrections are welcome.

| 方向 / Direction | 语言包 / Packs |
|------|------|
| 中文候选 → 外语 / Chinese candidates → | `zh-en` `zh-ja` `zh-ko` `zh-fr` `zh-de` `zh-es` `zh-ru` |
| 英文候选 → 外语 / English candidates → | `en-zh` `en-ja` `en-ko` `en-fr` `en-de` `en-es` `en-ru` |

## 目录 / Layout

- `base/<语言包>.tsv`：由大语言模型生成的底稿，按词频从常用到不常用排列。不要直接修改：重新生成时会被覆盖。
  Generated translations, most frequent words first. Don't edit them: they are regenerated.
- `corrections/<语言包>.tsv`：人工修订，打包时覆盖底稿里的同一个词，重新生成也不会丢。
  Human corrections; they replace the same word in the base and survive regeneration.
- `tools/check.py`：格式与质量检查（每个 PR 自动运行）/ checks run on every pull request.
- `tools/build.py`：生成语言包（维护者使用）/ builds the packs (maintainers).

每行一个义项：词、读音（中文用拼音，如 `xian:zai`；英文留空）、词性、译文。
One line per sense: word, reading (pinyin such as `xian:zai` for Chinese, empty for English),
part of speech, translation.

```
时间	shi:jian	n.	time
发展	fa:zhan	v.	develop
发展	fa:zhan	n.	development
```
